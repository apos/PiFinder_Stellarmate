    What is this device?i
    StellarMate + PiFinder
    A Raspberry Pi with both StellarMate and PiFinder hardware, running standalone.
    ⚠ Needs a powerful Raspberry Pi to carry this combined role - Pi 5, NVMe storage, 8 GB RAM minimum.
    For development and testing: this installation also works in a X86 UTM/VM. Cedar can not be used, but there exists the PiFinder Simulator instead of a real camera/solver.
    StellarMate + Control host only
    No PiFinder hardware used on this device - it couples to a PiFinder running elsewhere via network (both devices must be in the same network). This machine is the StellarMate and PFSM Control Host; the PFSM Control Center also runs here. Installs and configures the PiFinder LX200, PiFinder Mount Bridge and PiFinder Simulator INDI drivers - the Simulator lets you test the coupling without a real PiFinder present.
    ⚠ The remote PiFinder needs the PiFinder LX200/Mount Bridge INDI drivers built, and a safety patch applied to its own pos_server.py (prevents a fake position being sent when unsolved) - not yet a ready-made script, see issue #401.
    ⚠ A powerful machine for astrophotography tasks - a strong StellarMateOS on Pi 5 (NVMe, 8 GB min.), or an x86 StellarMateX.
